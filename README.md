#  Chocolate Cake Delivery App

A premium Chocolate Cake Delivery App UI built using React Native and Expo.
The app focuses on React Navigation concepts including Stack Navigation, Bottom Tabs, Drawer Navigation, Auth Flow and Deep Linking.

---

#  Features

* Stack Navigation
* Bottom Tab Navigation
* Drawer Navigation
* Authentication Flow
* Custom Headers
* Smooth Screen Transitions
* Cart & Orders Flow
* Persistent Login using AsyncStorage
* Responsive UI
* Deep Linking Support

---

# 🛠 Tech Stack

* React Native

#  Navigation Structure

↓
Bottom Tabs
├── Home Stack
│   ├── Home Screen
│   ├── Restaurant Detail
│   └── Cart
├── Search
├── Orders
└── Profile Drawer
├── My Orders
├── Settings
├── Help
└── Logout

---

#  Auth Flow

User login state is stored using AsyncStorage.
After app reload, user remains logged in until logout.
